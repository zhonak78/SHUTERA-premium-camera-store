DÔLEŽITÉ — KAŽDÝ PRODUKT SAMOSTATNE

Every individual accessory must have its own unique product page.

For example:

SHUTERA Tripod Pro → its own page
SHUTERA 128 GB Memory Card → its own page
SHUTERA 1 TB External SSD → its own page
SHUTERA Battery X1 → its own page

Do not show the same text or specifications for different products.

AUTOMATICALLY SCROLL TO THE TOP

VERY IMPORTANT:

Whenever the user clicks a product and opens a new product detail page, the page must automatically scroll to the very top.

The user must always start the new product page from the beginning.

Do not preserve the previous page's scroll position.

When navigating to a product page, use smooth scrolling to the top:

window.scrollTo({ top: 0, behavior: "smooth" })

If the website uses routing/navigation, make sure the scroll position is reset every time a new product page is opened.

This must work for:

Fotoaparáty
Profesionálne fotoaparáty
Videokamery
Objektívy
Statívy
Tašky a batohy
Pamäťové karty
Externé disky
Batérie
Nabíjačky

Every product click → new product page → scroll position = 0.
